# YPS Reactive Form Backend

Standalone Node.js API for the YPS student admission frontend.

## Run

Run `npm start` in this folder. The API listens at `http://localhost:3000`.

Student records are saved to `data/students.json`. The API accepts the frontend origin at `http://localhost:4200` by default. Configure `PORT`, `HOST`, or comma-separated `CORS_ORIGINS` as needed.
